Project 08TrainingDone

Shadowing the ARCHIE Project

I shadowed the ARCHIE project to learn how mitochondrial transplantation into granulocytes is done in practice. I learned a different wet-lab approach using the PORTER machine, which directly reshaped my own neutrophil experiments.

What I learned

  • Mitochondrial extraction in practice differs a lot from what published papers describe, with a gentler protocol overall.
  • The PORTER approach keeps mitochondria in blood and stabilises them, instead of isolating them.
  • Isolated mitochondria are highly sensitive, which explains my earlier results.

Why it mattered

This training is what turned my May–June negative results into a clear next experiment. See the neutrophil project.
